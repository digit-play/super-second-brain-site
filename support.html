客服支援

使用超級第2腦遇到問題，我們會協助確認。

提出問題前

  • 確認網路連線正常。
  • 在 App「設定」最下方查看版本與組建號。
  • 記下問題發生的時間與操作步驟。

常見問題

搜尋需要多久？
AI 整理期間會顯示搜尋中提示；繁忙時可能需要稍候。

刪除 App 會刪除伺服器資料嗎？
不會。請依照帳號刪除流程移除伺服器資料。

可以修改辨識錯誤的紀錄嗎？
可以。點擊紀錄卡片後修改內容或日期，系統會重新分類。

聯絡管道

目前為上架準備階段。一般問題可前往 GitHub 客服問題頁。

GitHub 問題頁是公開的，請勿張貼電話、Email、帳務內容、生活紀錄或其他個人資料。專用客服信箱會在正式上架前補上。
